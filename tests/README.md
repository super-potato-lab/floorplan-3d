# P0 回归测试

使用 Node.js 20 或更新版本，无需安装依赖：

```bash
node --test tests/*.test.cjs
```

测试从 `index.html` 提取真实函数，在隔离的 VM 中模拟 DOM、存储和 3D 失败。
覆盖导入校验、注入字段、原方案保留、旧格式兼容、撤销重做、存储恢复和 3D 重试。
它们不替代浏览器布局、触屏或真实 WebGL 测试。

方案现在带 `schemaVersion: 1`；没有版本号的旧方案仍可导入。
文件限制为 2 MB、500 件家具、1000 条测量线；尺寸为 50–20000 mm，坐标范围为 ±1000000 mm。
已提供的家具和房间记录必须完整，材料和家具类型必须来自内置库。
导入不允许拆除承重墙或外墙。

损坏的本地方案不会在加载时被覆盖。界面提供原始数据导出；首次成功保存前，会先把原始数据备份到 `huxing-design-v1-recovery`。
备份或保存失败时，界面保留失败提示及重试、导出入口。

浏览器验收建议：

- 导出当前方案并重新导入，确认家具、材料、测量与拆墙标记一致。
- 导入缺失材料、未知类型或恶意属性的文件，确认画面和已存方案不变。
- 模拟 localStorage 写入失败，修改布置，确认失败提示和导出仍可用。
- 模拟 WebGL 初始化/渲染失败，确认回到 2D，恢复后可重新进入 3D。
- 在窄屏确认保存提示、重试及备份按钮可见。
