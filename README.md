# 户型装修设计

中文 | [English](README.en.md)

纯前端的户型装修设计工具：在 2D 平面图上摆放家具、拆改墙体、测量尺寸，一键切换到 Three.js 3D 场景，可以鸟瞰，也可以第一人称漫游。整个应用就是一个 `index.html`，无需构建，打开即用。

## 功能

**2D 平面布置**
- 按原始户型 1:60 / 1:100 比例显示，尺寸单位 mm
- 从左侧家具库拖入 60 余种家具家电（卧室、客厅、餐厨、卫浴、家电、书房休闲）
- 拖动移动、旋转（Shift 自由角度）、调整尺寸，贴墙自动吸附
- 测量工具（靠近墙面自动吸附，Shift 锁定水平 / 垂直）
- 拆改非承重墙，承重墙单独标示
- 图层开关：尺寸标注、房间名、家具、网格、承重墙

**3D 场景**
- 鸟瞰、斜视、俯视多种视角，点击房间列表可飞到对应房间
- 漫游模式：桌面端 WASD + 鼠标，触屏设备用虚拟摇杆，可以点门开关
- 全高墙 / 剖切墙切换，日照时间滑块，夜景灯光
- 精细家具模型：柜门分缝与拉手、软包床头、带环境反射的金属与陶瓷材质等
- 在 3D 中也能选中、拖动家具，与 2D 方案实时同步

**方案与统计**
- 房间面积与套内使用面积自动统计
- 为每个房间更换地面材料（木地板、地砖、大理石、水磨石、地毯等），按面积加 5% 损耗估算造价
- 撤销 / 重做，方案自动保存在浏览器本地
- 中文 / English 界面切换（顶栏右侧按钮，默认中文，选择会记住）
- 导出 PNG 图片，导出 / 导入方案 JSON

## 快速开始

```bash
git clone <仓库地址>
cd <仓库目录>
```

然后直接用浏览器打开 `index.html`。也可以起一个本地静态服务器：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```

> Three.js 通过 jsDelivr CDN 加载，首次打开 3D 场景需要联网。

## 技术栈

- 原生 HTML / CSS / JavaScript，无框架、无构建步骤
- 2D 平面图用 SVG 绘制
- 3D 场景用 [Three.js](https://threejs.org/) r160（OrbitControls、PointerLockControls、RoundedBoxGeometry、RoomEnvironment、CSS2DRenderer）
- 数据保存在 `localStorage`

## 自定义户型

户型数据写在 `index.html` 里：

- `ROOMS`：房间多边形、名称、默认地面材料
- `WALLS` / `WINS`：墙体与窗洞
- `MATS`：地面材料名称与单价
- `LIB`：家具库（类型、名称、默认尺寸、颜色）
- `buildFurniture()`：各类家具的 3D 模型

改这些数据就能换成自己的户型。

## 导入自己的户型（P1 Beta）

入口：[通用户型工作区](https://super-potato-lab.github.io/floorplan-3d/planner/)。旧版示例编辑器继续保留，两个工作区独立保存。

1. 上传 PNG、JPG、WEBP 或 PDF（15 MB 以内，PDF 可选页）。底图会缩至最长边 1600 像素。
2. 选择本地提取墙线，或 AI 识别墙与门窗。先预览数量，再应用草稿；应用可撤销。
3. 点击标定尺寸，在底图选择已知尺寸的两端，输入毫米长度并确认。未标定时 3D 仅供比例预览。
4. 补画或拖动墙线，修改厚度和高度，在连续墙体上放置门窗。检查未连接墙端和闭合房间。
5. 点击“生成 3D”，或导出 v2 JSON 保存含底图的方案。

本地识别只提取水平/垂直的深色墙线，不识别文字、门窗或承重性质；手工编辑支持任意角度的直墙。云端视觉识别也可能错位、漏识别，结果必须核对。当前不支持曲面墙、复式楼层、照片透视校正、自动家具识别或施工级精度。无尺寸图无法推断真实大小。

“体验图片识别”可直接演示完整流程。家具目前提供尺寸可调的占位块，旧编辑器的精细家具库尚未接入通用工作区。旧版 JSON 继续在原编辑器导入，不能作为通用 v2 几何数据导入。

### 保存与隐私

方案自动保存在当前浏览器，导出 JSON 可跨设备备份。保存失败会持续提示；损坏缓存先备份后写入新方案。图片和 PDF 的本地识别不上传文件。**点击 AI 识别会把压缩底图发送至 Cloudflare Workers AI**；Worker 不记录图像、提示词或结果，仅保存额度计数。3D 与 PDF 库从固定版本 jsDelivr 加载。

### 识别服务

服务源码在 `server/`，部署到 Cloudflare Workers；前端地址在 `planner/config.mjs`。AI 使用 Workers AI 绑定，浏览器和 GitHub 均不存放 API 密钥。部署参数见 `server/wrangler.jsonc`。后端部署独立于 GitHub Pages，修改 `server/` 后需另行部署。

公开 Beta 的硬上限：全站每天 20 次、整个试用累计 100 次，调用间隔至少 10 秒；失败调用也计入额度。额度由 SQLite Durable Object 事务控制，重启不会清零。调用可能消耗账户 Workers AI 配额/费用；到达上限直接拒绝，不自动提高额度。本地提取不受此限制。CORS 仅限制浏览器来源，并非身份认证；公开服务的试用额度可能被其他人占用。正式开放前应增加登录或 Turnstile，再按用户分配额度。

### 验证

`node --test tests/*.test.cjs`：包含旧编辑器 P0 和通用 v2 模型、闭合房间、门窗开洞、尺寸换算、本地识别、云端输入输出校验。自动化测试使用矩形、L 形、斜墙与多房间合成图，不代表真实户型图的识别准确率。
